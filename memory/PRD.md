# Xaluca Tours — PRD / Estado

## Problema original
App full-stack (React + FastAPI + MongoDB) para agencia de viajes a medida por Marruecos, heredando el sistema de diseño premium "Grup Xaluca" (Dark Academia, zellige, acentos dorados #D4A373). Trilingüe (es/en/fr), mapas Leaflet, CMS global editable por slots, audio global persistente, notificaciones por email (Resend), galería Pexels/Unsplash, precios por ruta.

## Arquitectura
- backend/server.py — CMS slots, leads CRUD, files, integraciones, Resend
- frontend/src/lib/{routes.js, routeComponents.js, allTripsCatalog.js, pricing.js, programPricing.js, preciosData.js, homeCarousels.js}
- frontend/src/pages/{PreciosPage.jsx, AdminPage.jsx}
- Idioma por defecto (es) en raíz; en/fr bajo /<lang>/<slug>

- **Herramienta de migración de galerías a clave definitiva (jun 2026) — COMPLETADO + TESTEADO**: Botón "Migrar galerías a clave definitiva" en el header del Gallery Dashboard (`GalleryManager`, `data-testid=gallery-migrate-btn`). `runMigration()` (frontend, usa `TRIP_PROGRAMS`+`namespaceForRouteId`): Fase 1 copia cada galería de la clave antigua `${ns}.day.${id}` a la nueva indexada `${ns}.day.${index}.${id}` (a TODOS los días que comparten id en programas con colisión → opción usuario 1a), saltando las ya migradas; Fase 2 limpia las claves antiguas consumidas (solo tras copiarlas). - **Recuperación retrocompatible de galerías tras el cambio de clave (jun 2026) — COMPLETADO + TESTEADO**: El cambio anterior a clave indexada `${ns}.day.${index}.${dayId}` provocó que en PRODUCCIÓN las galerías guardadas con la clave antigua `${ns}.day.${dayId}` dejaran de mostrarse (solo aparecía 1 imagen/día por fallback). Los DATOS NO se perdieron (siguen en la BD bajo la clave antigua). FIX retrocompatible: `DayImageGallery` lee la clave nueva y, si está vacía, recurre a la antigua (`base`); `GalleryManager.seedFor` recupera también `galleries[legacyBase]`. Al re-guardar un día, migra a la clave indexada. Para días con `day.id` duplicado, el fallback puede mostrar la galería antigua compartida hasta el primer re-guardado (comportamiento previo, aceptable). Verificado en preview: día `dia-final` (galería legacy de 2 imgs) recuperado tanto en público (contador 1/2) como en admin (2 thumbs). REQUIERE REDESPLIEGUE para aplicar a producción.
